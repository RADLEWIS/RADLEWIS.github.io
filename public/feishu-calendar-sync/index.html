Feishu Calendar Sync

A personal utility by RADLEWIS that keeps Feishu events visible in a dedicated Google calendar.

What it does

The utility reads the owner's Feishu calendar using CalDAV and copies event titles, start and end times, descriptions, and locations into a Google calendar named “飞书（自动同步）”. It runs on the owner's server approximately every five minutes.

Changes flow from Feishu to Google Calendar. Events are edited in Feishu. The utility copies events starting within the past 30 days and the coming year, expands recurring events into individual occurrences, and updates or removes managed copies when the source changes within that window.

Google account access

The owner authorizes access through Google's sign-in and consent screens. The utility requests only https://www.googleapis.com/auth/calendar.app.created, which permits it to create and manage calendars created by the application. It does not request access to Gmail messages or other existing calendars.

Personal use

This is a private integration for the developer's own accounts. There is no public sign-up or hosted synchronization service. This website provides information about the application; calendar data and credentials are not uploaded to this website.
